## 5. 固定流程（每张前端卡）

1. 建卡，`specs/CURRENT` 指向新卡，填写 DoD 与 scope。
2. 卡内含后端时后端先行：测试先行 → 实现 → `check.py` 绿。
3. Penpot 出稿：1440 画板，复用 `04-tokens.md` 令牌，不发明新色值。
4. 导出 2 倍快照到 `docs/design/03-hifi/`，同步 `04-tokens` / `05-components` / `06-acceptance`。
5. 停下来贴图等用户确认，把结论写进第 3 节；未确认前不写前端代码。
6. 确认后实现前端，组件测试覆盖正常 / 空 / 加载 / 错误 / 竞态。
7. `check.py` 退出码 0 + 手动验收表填写 + 一卡一提交。
