## 0. 怎么用这份清单

- 任务编号在每张卡内从 T1 重新开始；状态图例：`[ ]` 待做 · `[x]` 完成并已跑过 check.py · `[~]` 做了但前提未满足。
- 一张卡 = 一个可独立验收的交付物 = 一个 commit（大卡可拆多个 commit，但同一 commit 不跨卡）。
- 卡片按依赖排序；`015` 是条件卡，需先由 `002` 拍板是否采用桌面壳。
- P2 卡片是方向性拆解，开工前允许再细化；P0/P1 卡片的任务粒度按「最小可验证的一步」控制。
- 每张卡除 `check.py` 外，涉及界面 / 终端 / 托盘 / 真实外部接口的行为，必须在 `tasks.md` 追加「手动验收」记录（步骤 + 实际结果）；`check.py` 不能替代人工验收。
- 新增依赖必须在卡内写明理由，并同步 `uv.lock` / `pnpm-lock.yaml`（AGENTS.md 第 5 条）。
- 需求原文只定义「要什么」；本清单只做任务拆分，不替代 `requirements.md`。

| D-8 | F-16 合规边界 | 不代注册、不代购、不共享账号；优先官方，第三方推荐必须带免责声明 | 021 |

补充说明：

- **D-2 推荐理由**：列表稳定；F-01「已安装但未配置也要列出」自然成立；F-09 的颜色身份不会因为
  切换档案而跳变；F-13 群聊的对比对象仍是「不同的 AI」。
- **D-3 推荐理由**：F-03 已要求「同一档案可复用到多个工具、同一工具可在多档案间切换」，
  这由应用侧档案库承担；工具文件只保留当前生效值，写入面最小。
- **D-5 推荐理由**：P0 先保证核心闭环，避免 Tauri 工具链拖慢验收；F-11 可由本地后端拉起终端，
  F-17 的托盘 / 快捷键 / 自启才真正需要桌面壳，因此把 015 设为条件卡。
- **D-6 推荐理由**：满足「档案是配置，密钥是凭证」的概念分离；若 Linux 环境没有 Secret Service，
  回退到 0600 文件并在界面明确告知。

## 5. 每张卡的开工与验收 SOP

1. 复制 `specs/_template/` 为 `specs/NNN-<短名>/`，填写 `spec.md` 的 DoD 与 `scope` 块。
2. 把 `specs/CURRENT` 改成该卡编号；不改会导致 `guard scope` 跳过范围校验。
3. 先写失败用例（测试规则：先确认它因功能没写而失败，不是 import 错误）。
4. 实现到测试变绿；前端行为优先用 `getByRole` / `getByText` 断言。
5. 跑 `uv run python scripts/check.py`，把**完整输出**贴进该卡 `tasks.md` 的「验收记录」。
6. 涉及界面 / 终端 / 托盘 / 真实外部接口的卡，追加「手动验收」表：操作步骤、预期、实际结果。
7. 一张卡完成后更新 `PROGRESS.md` 的「当前状态 / 下一个可执行命令」；一张卡 = 一个 commit。
8. 新增依赖必须写理由，并同步更新 `uv.lock` / `pnpm-lock.yaml`。

## 6. 明确不做与风险

### 6.1 明确不做（摘自需求 §6，作为所有卡的边界）

- 不做云端同步、账号体系、服务端。
- 不做 API 转售、账号池、共享密钥。
- 不自己实现 Agent 能力；工具调用、权限确认、沙箱、MCP 交给被管理工具。
- 不修改被管理工具的安装目录或程序本体，只动用户级配置。
- 不做移动端。
- 不做模型训练、微调、本地推理引擎。
- 不绕过任何官方计费、授权或地区限制。
- 不接管用户登录态；OAuth 凭据只备份与还原，不解析、不迁移、不共享。

### 6.2 风险与假设

- D-1～D-8 已于 2026-11-08 确认；若需改变，先更新 `docs/decisions.md` 与 `PROGRESS.md`，再重排受影响卡片。
- 工具配置格式可能随版本变化：每个适配器必须有 fixture、版本检测与「不认识就只读降级」。
- 密钥存储依赖 OS keyring 时，Linux 环境可能缺失 Secret Service；必须有 0600 文件回退。
- GUI / 终端 / 托盘行为无法由 `check.py` 覆盖，必须保留手动验收记录，避免「测试绿但功能不可用」。
- F-14 的价格数据需要维护；离线时只能使用内置或手动价格表，且必须显示估算口径。
- 当前开发机为 Windows，macOS / Linux 的差异必须由 017 的三平台 CI 或真机验证兜底。
- P2 卡片不代表已承诺范围；P0/P1 达成并真实使用两周后再排期。
