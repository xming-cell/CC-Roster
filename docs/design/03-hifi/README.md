## 命名规范

```
NN-<ascii-名称>.png
```

示例：`04-workbench-empty.png`、`05-workbench-partial-failure.png`。

**文件名只用 ASCII**：`scripts/guards.py` 读 `git diff` 输出时，中文路径会被 git 转义成八进制，导致 scope 校验误报越界。画板的中文名写在上面表格里即可，不必体现在文件名上。

## 导出步骤（Penpot 界面）

1. 打开文件「新建文件 1」→ 页面「主页面」
2. 在图层面板选中画板（如 `工作台 · 1440`）
3. 右侧「导出」→ 选 PNG、倍率 `2x`（1440 宽画板得到 2880 像素）
4. 按上表命名后放入本目录

> 2 倍图：1440 宽画板导出为 2880 像素，便于放大检查细节。

## 约定

- 只放**定稿**快照，中间稿不要提交（会不断膨胀）。

- 不要把 `.penpot` 源文件放进来——源文件在 Penpot 账号里，见 `07-design-source.md`。
