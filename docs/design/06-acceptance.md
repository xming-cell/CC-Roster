## D. 会话区

| 编号 | 前置 | 操作步骤 | 预期结果 |
|---|---|---|---|
| D-1 | 工具不支持应用内对话 | 选中该工具 | 输入框不可用并给出替代入口说明，不显示可输入的空框 |
| D-2 | 工具支持对话 | 输入内容后按 Enter | 消息立即上屏，状态变为执行中，发送按钮变为停止 |
| D-3 | 执行中 | 点击停止 | 执行中断，消息保留并标注「已停止」 |
| D-4 | 发送失败 | 模拟网络/后端错误 | 消息标注失败并可重试，不出现成功态 |
| D-5 | 无项目目录 | 点击「新建会话」 | 先要求选择项目目录，取消则不开会话 |

## E. 写入类动作（切换供应商）

> 对照画板：`供应商切换 · 预览` / `供应商切换 · 结果` / `供应商切换 · 冲突`（1440×900）。

| 编号 | 前置 | 操作步骤 | 预期结果 |
|---|---|---|---|
| E-1 | 同一工具至少两个供应商 | 在供应商页点击目标供应商的「切换」 | 出现预览：影响范围（工具 → 供应商）、按文件分组的字段 before/after、涉及文件数、重启要求、底部只读提示；磁盘未变化 |
| E-2 | 预览已打开 | 点击取消或按 Esc | 不产生任何写入；审计无 apply 记录；焦点回到触发按钮 |
| E-3 | 预览已打开 | 点击「应用切换」 | 按钮进入写入中并禁止重复点击；成功后显示「切换完成」、快照卡片、文件名与 hash、审计入口 |
| E-4 | 预览后手动修改目标文件 | 点击「应用切换」 | 显示冲突态：红色面板说明未写入、文件路径、预览时间与检测时间；提供「重新检查」与「取消」 |
| E-5 | 目标文件只读 / 目录无权限 | 打开预览 | blockers 可读列出文件与原因；「应用切换」不可用并说明原因 |
| E-6 | 预览已打开 | 快速重复点击「应用切换」 | 只产生一次写入；第二次被锁定或幂等返回，不出现双份快照 |
| E-7 | 应用成功 | 点击结果页「回滚」 | 出现回滚确认；确认后文件与快照逐字节一致，结果页切到已回滚状态 |
| E-8 | 应用成功 | 点击「查看操作记录」 | 跳到操作记录并定位本次 apply（含工具、供应商、文件、字段、结果、快照） |
| E-9 | 应用 / 回滚完成后 | 检查审计 JSON | 无密钥明文、无文件原文、无完整请求体 |
