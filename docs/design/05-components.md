## 4. 可访问性要求

1. **图标按钮必须有可读名称**：`aria-label="新建会话"`，并在 hover / focus 时显示 tooltip。
2. **焦点可见**：所有可交互元素需要 `:focus-visible` 描边 `2px #2563EB`，偏移 `2px`；不得用 `outline: none` 静默移除。
3. **对比度**：
   - `#64748B` 于 `#FFFFFF` ≈ 4.76:1，正文可用；
   - `#94A3B8` 于 `#FFFFFF` ≈ 2.58:1，**不满足 4.5:1**，只能用于纯装饰；占位文字、11px 元信息请改用 `#64748B`。
4. **状态不只靠颜色**：所有徽章带文字（正常 / 未配置 / 异常）。
5. **点击目标**：桌面端不小于 `24 × 24`，主操作不小于 `32 × 32`。
6. **键盘顺序**：主导航 → 列表面板 → 工具头按钮 → 消息区 → 输入框；`Esc` 关闭浮层，`Enter` 发送、`Shift+Enter` 换行。
7. **语义化**：导航用 `nav` + `aria-current="page"`；消息列表用 `role="log"`；输入区用 `textarea` + `aria-label`。
