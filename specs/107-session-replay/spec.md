# 033 — 会话历史回放

> 来源：`docs/task-plan2.md` 的 107 号规划卡；正式编号 033。
> 依赖：106（会话列表与详情的数据形状）；后端 sessions / 回放接口已存在。

## 背景与目标

1. 工具自身产生的历史会话散落在各目录，用户无法在应用内查看。
2. 目标 1：按工具 / 项目 / 最近活动组织会话列表，打开即用，不需要导入。
3. 目标 2：时间线区分 user / assistant / tool_call / tool_result / system，未知类型降级但不静默。
4. 目标 3：只读保证与可用的性能；读取前后原始文件 hash 不变。

## 验收标准（DoD）

- `uv run python scripts/check.py` 退出码 0。
- 会话列表按工具 / 项目 / 最近活动组织；未知项目路径显示为「未知项目」。
- 时间线区分五种类型；未知类型显示「未知类型」与原始摘要，不直接丢弃。
- 分页 / 懒加载可用；上百会话、几十 MB 记录不卡顿（给出实测口径）。
- 只读：读取前后原始文件 hash 一致。
- 空 / 加载 / 部分失败 / 单工具失败有可读状态，不阻塞其它工具。
- 设计稿已在 Penpot 出稿、导出快照并获用户确认（记录在 `docs/task-board.md`）。
- 测试与手动验收完成并回填。

## 边界用例（实现时必须想到）

1. 工具目录为空 / 不存在 / 无权限 → 可读状态，不显示 0 条假成功。
2. 单个会话文件损坏 / 编码异常 → 该条降级，其它条目可用。
3. 时间线里有未知 role / 空内容 / 超长工具结果 → 折叠并提供完整查看。
4. 翻页过程中切换工具 → 迟到响应不覆盖当前工具。
5. 同一会话在查看期间被工具追加 → 不因自动刷新跳动；明确刷新入口。

- 不做跨工具全文搜索（ADR-014）。
- 不改后端回放契约；发现缺口先记未决问题，不顺手扩 scope。
- 不做 106 的实时对话与 108 的信息页。
