# 034 — 操作记录、用量与设置

> 来源：`docs/task-plan2.md` 的 108 号规划卡；正式编号 034。
> 依赖：101（壳）、104（审计 action 扩展）；后端 audit / usage / settings / appearances / desktop 已存在。

## 背景与目标

1. 补齐三张信息页：操作记录、用量、设置，让用户能审计、看消耗、调全局偏好。
2. 目标 1：操作记录按时间展示动作、工具、供应商、文件 / 字段、结果与快照入口，支持按工具筛选，无密钥。
3. 目标 2：用量展示调用次数、token 与估算花费；未知价格明确标未知，只展示不扣费，并说明估算口径。
4. 目标 3：设置覆盖外观偏好、只读模式、快捷键、开机自启与隐私 / 本地数据说明；平台不支持的能力隐藏或说明。

## 验收标准（DoD）

- `uv run python scripts/check.py` 退出码 0。
- 操作记录：时间倒序、可筛选工具、空 / 加载 / 错误齐全；条目可跳到对应快照入口（若存在）。
- 用量：汇总与明细口径一致；未知价格显示「未知」而不是 0；页面说明「仅展示、不扣费」。
- 设置：外观偏好即时生效或明确保存结果；只读、快捷键、自启按平台能力探测，不支持时隐藏或标注。
- 隐私 / 本地数据说明写明数据目录、日志、脱敏边界与清除方式。
- 三个页面都不出现空壳入口；未接入的入口不显示。
- 设计稿已在 Penpot 出稿（三张画板）、导出快照并获用户确认（记录在 `docs/task-board.md`）。
- 组件测试与手动验收完成并回填。

## 边界用例（实现时必须想到）

1. 审计为空 / 只有失败记录 / 单工具无记录 → 状态文案正确，不显示假数据。
2. 审计条目缺字段、快照已删除 → 显示「不可用」，不报整页错误。
3. 用量为 0、价格未知、混合模型 → 汇总不出现 NaN / Infinity。
4. 外观保存在后端失败 → 回滚 UI 状态并提示，不假装成功。
5. 平台不支持快捷键 / 自启 → 隐藏或明确说明，不显示无效开关。
6. 只读模式开启时，所有写入口禁用并说明原因。

## 不做（明确划界）

- 不做扣费、充值、账单导出。
- 不做审计全文搜索、导出 CSV（ADR-014 搜索筛选不纳入）。
- 不做主题编辑器与自定义配色；只做已有外观偏好的选择。
- 不改后端 settings / audit / usage 契约；发现缺口先记未决问题。
