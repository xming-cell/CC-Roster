# 005a — 前端信息架构基线

## 背景与目标
- 前端已回退到基础页面，后端能力保留；在重新设计 UI 前先明确页面、导航和用户任务。
- 提供可由产品与设计继续迭代的信息架构示例，不预设视觉风格。

## 验收标准（DoD）
- `uv run python scripts/check.py` 退出码 0。
- `docs/design/01-ia.md` 描述产品对象、导航层级、页面职责与关键用户流程。
- 文档区分当前前端已有页面与后续设计目标，不把未接入的能力描述为已完成。
- 文档不规定颜色、字体、图标、间距等视觉表现。

## 范围

```scope
docs/design/01-ia.md
```

## 边界用例（实现时必须想到）
1. 已发现但未配置的工具仍可从工具列表进入详情。
2. 空列表、加载失败、工具异常和部分失败均有明确页面状态。
3. 需要写入配置的流程必须先预览变更，并提供取消路径。

## 不做（明确划界）
- 不修改前端组件、路由、样式或测试。
- 不修改后端实现或 API。
- 不决定视觉设计规范；相关规范留给后续设计产物。
