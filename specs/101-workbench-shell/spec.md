# 027 — 前端应用壳与工作台工具列表

> 来源：`docs/task-plan2.md` §5 的 101 号卡（规划稿临时编号），正式编号 027。
> 依赖：026（V2 决策与设计基线）已完成；设计依据为 `docs/design/01-ia.md`、`04-tokens.md`、`05-components.md`、`06-acceptance.md`。
> 性质：前端实现卡。只动 `frontend/`，不新增或修改后端接口。

## 背景与目标
- 前端目前仍是最小骨架：`/` 是健康状态页，`/tools` 是工具列表与详情，导航没有按 V2 IA 组织，用户打开后无法一眼看出「有哪些工具、谁需要处理」。
- 目标 1：把应用壳换成 V2 IA 的工作台骨架——主导航 + 工具列表面板 + 工具详情面板，默认入口就是工作台。
- 目标 2：让用户在 3 秒内识别出本机工具、安装/配置状态、当前供应商与模型，并看到异常或未配置项。
- 目标 3：复用现有 `api/tools.ts` / `stores/tools.ts` 的领域逻辑，把加载、空、错误、部分失败与未选中状态补完整，不另起请求层。

## 验收标准（DoD）
- `uv run python scripts/check.py` 退出码 0。
- 默认路由 `/` 打开工作台：左侧工具列表、右侧当前工具详情或未选中空状态；访问 `/tools` 仍落到同一工作台（路由重定向或等价实现）。
- 应用壳有稳定主导航；只显示当前真正可用且有页面状态的入口。供应商、操作记录、用量、设置等未实现页面不得出现空壳入口。
- 工作台工具列表每项显示：名称、安装/配置状态、当前供应商摘要、当前模型摘要；异常与未配置工具保留在列表中，正常工具不因前两者被隐藏。
- 列表面板头部显示工具总数与需要处理数量（异常 + 未配置）；列表不提供搜索框或筛选控件（ADR-014）。
- 加载、空列表、整体读取失败、部分失败、未选中五种状态都有可读且互不混淆的界面文案；首次扫描完成前不得先显示「正常」再跳变。
- 选中工具后右侧详情至少显示：状态、安装 / 配置情况、供应商、模型、接口地址、密钥脱敏状态、配置路径、最后修改时间与 warnings；未配置工具同样可以进入详情。
- 详情请求失败时右侧显示可读错误，左侧列表保持可用；重新选择该工具应重新发起请求并可恢复，不把错误带到其他工具。
- 复用并重构 `frontend/src/api/tools.ts` 与 `frontend/src/stores/tools.ts`，不新增第二套工具请求层；请求仍统一走 `api/` 与 `ApiError`。
- 键盘可达：导航与工具条目可用 Tab 到达，当前导航带 `aria-current`，选中项状态可被读屏识别；`:focus-visible` 清晰可见；状态不只靠颜色传达。
- 组件测试使用 `getByRole` / `getByText` 覆盖上述状态与交互；`check.py` 的 frontend tests 全绿。
- 手动验收：桌面宽度打开默认页，3 秒内能识别为工具列表；空 / 错 / 部分失败可复现。对照 `06-acceptance.md` 的 A-1～A-4、C-1～C-4、F-1 / F-3 / F-4 适用部分。

## 边界用例（实现时必须想到）
1. 空列表：文案区分「尚未发现工具」与「读取失败」，并说明扫描不修改配置。
2. 单个工具异常或配置损坏：该条目仍可选中；其他工具与顶层 warnings 仍可使用，不阻塞列表。
3. 未配置工具：仍可进入详情；供应商 / 模型缺失时显示「未知」，不编造默认值。
4. 首次加载：先显示「检测中」与骨架；扫描完成前不得渲染「正常」。刷新时保留旧列表，并在列表头标明正在重新检测，避免已选详情闪烁。
5. 快速连续选中 A → B：B 的详情不得被 A 的迟到响应覆盖；重复点击同一工具不产生重复请求或重复详情块。
6. 详情读取失败后选中另一个工具：错误状态必须清除，不把上一个工具的错误带到新工具。
7. 超长工具名、模型名、供应商名与配置路径：不撑破布局、不产生整页横向滚动；路径可换行，完整值仍可查看。
8. 键盘：Tab 顺序为导航 → 工具列表 → 详情操作区；Enter / Space 选中工具；不得用 `outline: none` 移除焦点样式。
9. 窗口收窄到桌面最小可用宽度：三栏允许收窄或详情下移，但不得出现整页横向滚动。
10. warnings 从有到无切换：不残留上一次的部分失败提示。

## 不做（明确划界）
- 不改后端、`backend/**`、API 契约或 `ToolView` 字段；供应商与模型摘要直接使用现有 `provider` / `model`。
- 不做供应商页、切换供应商、工具健康检查、操作记录、用量、设置页面及其导航入口（留给 102–108）。
- 不做对话 / 会话列表、新建会话、聊天输入与流式消息（留给 106）；本期工作台主区域只承载工具详情。
- 不做搜索、筛选、排序控件（ADR-014）。
- 不做暗色模式与主题切换（`04-tokens.md` §8：首版只交付亮色）。
- 不引入图标库、组件库或其他新依赖；图标用内联 SVG 或现有资源。
- 不做桌面壳、启动器、引导流程与移动端断点。
