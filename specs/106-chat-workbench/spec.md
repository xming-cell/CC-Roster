# 032 — 对话工作台与思考强度

> 来源：`docs/task-plan2.md` 的 106 号规划卡；正式编号 032。
> 依赖：101 工作台壳、100 决策基线（ADR-011 思考强度能力驱动、ADR-012 项目派生）。
> 现状：后端已有 chat / sessions / SSE / 取消 / fake executor；`ChatSession` / `ChatCreateRequest` 尚无思考强度字段。

## 背景与目标

1. 工作台目前只能看工具与供应商，不能新建会话、发消息、看流式输出。
2. 目标 1：打通「选工具 → 选项目目录 → 选供应商 / 模型 → 新建会话 → 流式对话 → 停止 / 重试」主流程。
3. 目标 2：思考强度按工具能力暴露；不支持的工具有明确降级，不制造假选项。
4. 目标 3：工具不支持应用内对话时，展示已支持的替代入口（如启动器说明），而不是不可用的输入框。

## 验收标准（DoD）

- `uv run python scripts/check.py` 退出码 0。
- 新建会话对话框覆盖工具、项目目录、供应商、模型、思考强度；目录必须存在且可读，错误留在对话框内。
- 左侧会话列表按项目与最近活动组织；主区域始终标明当前工具、项目目录、供应商、模型与思考强度。
- 发送后可见流式 token、状态事件、工具调用；工具调用可折叠。
- 停止可中断且状态可见；失败保留输入并可重试；重复提交被锁定。
- 思考强度能力表有出处（CLI 参数或官方文档），只有声明的工具才显示选项；不支持时隐藏或明确说明不可用。
- SSE 断线、半包、乱序事件、切换会话时的迟到响应不串台。
- 测试使用 fake executor / SSE 边界，不真实调用外部 CLI。
- 设计稿已在 Penpot 出稿、导出快照并获用户确认（记录在 `docs/task-board.md`）。
- 手动验收：让工具读一个文件，看到过程 / 结果 / 中断。

## 边界用例（实现时必须想到）

1. 项目目录不存在 / 不可读 / 是文件而非目录 → 新建会话失败且不丢表单。
2. 工具未安装、供应商无模型、密钥缺失 → 对应字段禁用并说明原因。
3. 思考强度：工具不支持、取值非法、会话恢复时字段缺失 → 隐藏或按默认值处理，不造假选项。
4. 流式：空 token、超长消息、工具调用嵌套、事件乱序、连接中断、服务端 500。
5. 并发：快速切换会话 / 连续发送 / 停止后立即重试 → 不串台、不重复发送。
6. 会话被删除或不存在 → 可读状态并能回到列表。
7. 上百条消息的会话 → 首屏不卡，滚动到底部策略明确。

## 不做（明确划界）

- 不做群聊对比、搜索筛选、启动器 UI（ADR-014；替代入口只做说明与已有能力）。
- 不做项目 CRUD、项目备注、收藏；项目只从会话目录派生。
- 不改已有 SSE 事件契约的语义；只做增量字段与前端消费。
- 不在本卡做 107 历史回放与 108 信息页。

## 修订 A（2026-11-17 用户改向，优先于上文冲突项）

**新建会话**
- 去掉「新建会话对话框」。点击工具头右上角「+」立即创建会话，使用当前工具与该工具当前 active 的供应商。
- 项目目录取「该工具最近一条会话的 project_dir」；该工具还没有任何会话时，只弹一次目录选择，不重复询问。
- 模型默认供应商清单第一项，思考强度默认「默认（不指定）」；两者都可在上下文条内切换。

**上下文条内联切换**
- 上下文条里的「模型」「思考强度」是可点的胶囊，点击展开菜单就地切换。
- 切换只作用于**本会话后续消息**，不修改 active 绑定与工具配置；当前消息执行中时禁用切换。
- 模型只列该供应商的模型清单；思考强度只列能力表声明的档位；不支持的工具不显示强度胶囊。

**过程展示（仿 Codex / Claude Code 等 harness）**
- 思考块、工具调用、读取文件等过程默认折叠成单行：`▸ 运行 pytest -q`、`▸ 读取 app/main.py`，右侧显示状态与耗时。
- 运行中只展开「当前步骤」，已完成步骤立即折叠；流式文本正常显示。
- 单行点击后展开原始命令与输出（等宽、可滚动、可「收起」）；再次点击折叠。
- 对话完成时，全部思考与命令折叠，只保留最终回答 + 一行摘要（如「过程 · 3 步 · 42.8s」）。
- 失败时保留输入与失败原因，提供重试；不出现成功态。
- 不支持应用内对话的工具：输入区替换为只读说明，不渲染输入框。

**后端增量**
- `ChatSession` / `ChatSessionView` 增加 `model`（可空）；新增 `PATCH /api/chat/sessions/{id}` 更新 `model` / `reasoning_effort`，按供应商模型清单与工具能力表校验。
- 旧会话缺字段时按默认值读取；不改 SSE 事件契约。
